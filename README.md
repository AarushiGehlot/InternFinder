
# InternFinder

A beginner frontend project that helps students explore
internship opportunities through a simple, interactive interface.

## Features

- Search internships by keyword
- Filter opportunities by work location
- Save and unsave internships
- Keep saved internships after refreshing the page
- Responsive layout for desktop and mobile
- Application button demo

## Tech Stack

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server or your browser.

## Future Improvements

- Add more internship listings
- Add stipend and deadline filters
- Connect a real internship data source
- Improve accessibility and testing

## Note

This project uses sample internship listings.
The application buttons are demonstrations and do not
submit real applications.
